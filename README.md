# 🎬 Lampa Online Hub (Українська Онлайн-Збірка)

> **100% Безпечний Онлайн-Перегляд без Торентів для Іспанії та країн ЄС**  
> Повністю вирізано TorrServer, Jackett, Prowlarr та будь-які BitTorrent/P2P протоколи. Тільки прямий потоковий перегляд (HTTP/HTTPS та HLS `.m3u8`).

---

## 🇪🇸 Чому ця збірка безпечна для ЄС та Іспанії?

У країнах Європейського Союзу (зокрема в **Іспанії, Німеччині, Франції**) діє суворий моніторинг копірайту:
- **Як працюють штрафи за торенти?** Компанії з моніторингу авторських прав підключаються до публічних роздач BitTorrent (торент-свормів) і фіксують IP-адреси всіх пірів, які завантажують або роздають файли через протокол BitTorrent/DHT. Після цього провайдеру надсилається запит і користувач отримує офіційний лист із великим штрафом (в Іспанії та Німеччині — від сотень до тисяч євро).
- **Чому прямий онлайн безпечний?** Ця збірка використовує **виключно прямі HTTP/HTTPS запити** (як звичайний перегляд YouTube або Netflix). Ваш пристрій **не бере участі в P2P-роздачах**, не підключається до торрент-трекерів, не відкриває BitTorrent портів і не транслює ваш IP у публічні списки пірів.
- **Що було повністю вирізано зі збірки:**
  - ❌ Вирізано TorrServer, `torr.js`, `tracks.js`, `tstracks.js`, `tsTracksProbe`
  - ❌ Вирізано Jackett/Prowlarr парсери (`Parsers.js`, `presets.js`, `pubtorr.js`)
  - ❌ Вирізано Torrent Manager, Torrent Downloader, Concert TorrSearch
  - ❌ Заблоковано та приховано кнопку торентів (`.view--torrent`), пункт «Торренти» у головному меню та налаштування парсерів
  - ❌ Додано блокування у `plugins_black_list.json` від випадкового встановлення торент-плагінів

## ✨ Що входить до збірки (Найкраще онлайн):

### 🍿 Онлайн-провайдери та балансери:
1. **Bandera Online 2.0** (`BanderaOnline.js` + `crypto-js.min.js`):
   - Головний український онлайн-агрегатор від спільноти LME.
   - Підтримує джерела: **UAflix, Filmix** (з підтримкою авторизації), **Makhno, BambooUA, AnimeOn, Mikai, Starlight (Midnight), Franko, UASerials**.

2. **StreamHub** (`streamhub.js` + бекенд `streamhub/`):
   - Повноцінна інтеграція від проєкту [Treamz/streamhub](https://github.com/Treamz/streamhub).
   - Агрегує стріми з **HDRezka, Eneyida, UAFlix, UASerials та Kodik**.
   - Підтримує сезони та серії через TMDB, вибір аудіодоріжок і якість відео.
3. **Cinema (ByLampa)** (`plugins/cinema.js`):
   - Окремий модуль із кінематографічним фокусом від ByLampa.
   - Балансери, фільтрація за озвучками та якістю потоку.
4. **Showy** (`plugins/showy.js` + `plugins/showy/online.js`):
   - Швидкий онлайн-агрегатор для перегляду фільмів та серіалів (Filmix, Rezka, Collaps, Kodik, Bamboo, Eneyida).
5. **Онлайн МОД (NB557)** (`plugins/online_mod.js`):
   - Популярний балансер із підтримкою прямих потоків HDRezka, Filmix, FanSerials, Collaps (актуальна версія з фіксами 2026 року).
6. **UASerials (Швидка кнопка)** (`uaserials.js`):
   - Окрема кнопка прямо на картці фільму/серіалу для швидкого запуску перегляду з порталу UASerials в українському дубляжі.
7. **Hikka Anime** (`hikka.js` + `hikka/`):
   - Каталог і онлайн-перегляд аніме з українським дубляжем від `hikka.io`.
   - Розклад онгоїнгів, описи персонажів, сезони та серії.
8. **Kinobaza** (`kb.js` + `kinobaza/`):
   - Інтеграція з українською базою фільмів Kinobaza: офіційні українські трейлери, релізи, тематичні добірки.
9. **SaloPower** (`sp.js` + `SaloPower/`):
   - Онлайн-записи та повтори спортивних подій (футбол, баскетбол, бокс, теніс, кіберспорт).
10. **MyCinema** (`MyCinema.js`):
    - Каталоги популярних стрімінгових платформ: Megogo, Sweet.tv, Kyivstar TV, Netflix, Apple TV+, HBO Max, Amazon Prime.
11. **TryzubTV** (`ttv.js` + `TryzubTV/`):
    - Прямий перегляд українських телеканалів через HLS стрімінг (IPTV).
12. **CommunityWatches** (`cw.js` + `CommunityWatches/`):

## 🚀 Як запустити та встановити

### Спосіб 1: Локальний запуск на ПК або Mac (з роздачею на Smart TV)
У папці проєкту вже є готовий скрипт сервера з підтримкою CORS та автоматичною генерацією конфігурації для Smart TV:
```bash
python3 run_server.py
```
Сервер виведе в термінал:
- Посилання для браузера: `http://localhost:8080`
- Посилання у домашній мережі: `http://192.168.x.x:8080`
- Параметр для Samsung/LG TV (Media Station X): `192.168.x.x:8080/msx/start.json`

---

### Спосіб 2: Розгортання на GitHub Pages (Безкоштовно)
1. Створіть новий публічний або приватний репозиторій на GitHub (наприклад, `lampa-online`).
2. Запушіть файли з цієї папки:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГІН/lampa-online.git
   git branch -M main
   git push -u origin main
   ```
3. У репозиторії на GitHub відкрийте **Settings** → **Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка `/ (root)`
   - Натисніть **Save**.
4. За кілька хвилин ваш персональний онлайн-хаб буде доступний за адресою:
   `https://ВАШ_ЛОГІН.github.io/lampa-online/`

---

### Спосіб 3: Розгортання на Vercel (1 клік, надшвидкий CDN)
У репозиторії додано файл `vercel.json` з усіма необхідними CORS-заголовками:
1. Зареєструйтесь на [vercel.com](https://vercel.com).
2. Натисніть **Add New** → **Project** та імпортуйте ваш GitHub репозиторій.
3. Натисніть **Deploy**.
4. Ви отримаєте постійний HTTPS домен виду: `https://lampa-online-xxx.vercel.app`.

---

### Спосіб 4: Розгортання на Cloudflare Pages
1. У панелі Cloudflare перейдіть у **Workers & Pages** → **Create application** → **Pages**.
2. Підключіть свій репозиторій на GitHub.
3. Build setting: залиште порожнім (статичний HTML).
4. Натисніть **Save and Deploy**.

---

## 📺 Налаштування на телевізорах (Smart TV)

### 1. Samsung Smart TV (Tizen) & LG Smart TV через Media Station X (MSX):
1. Встановіть безкоштовний додаток **Media Station X** з офіційного магазину Samsung Apps або LG Content Store.
2. Відкрийте MSX на телевізорі.
3. Перейдіть у **Settings** → **Start Parameter** → **Setup**.
4. Введіть адресу вашого хостингу:
   - Якщо локально: `192.168.x.x:8080/msx/start.json`
   - Якщо GitHub Pages: `ВАШ_ЛОГІН.github.io/lampa-online/msx/start.json`
   - Якщо Vercel: `lampa-online-xxx.vercel.app/msx/start.json`
5. Натисніть галочку і підтвердіть перезапуск MSX. Lampa відкриється на весь екран!

### 2. LG Smart TV (webOS) напряму через Homebrew Channel / Dev Mode:
У репозиторії є готовий маніфест `appinfo.json`. Ви можете зібрати `.ipk` пакет:
```bash
ares-package .
ares-install com.lampaonline.tv_2.0.0_all.ipk
```
Або у Homebrew Channel додати посилання на веб-додаток.

### 3. Android TV / Google TV:
- Відкрийте веб-браузер на телевізорі (наприклад, TV Bro, JioPages) і перейдіть за адресою вашого хабу.
- Або встановіть офіційний клієнт Lampa Android APK та у налаштуваннях вкажіть URL вашого онлайн-хабу.

## ⚙️ Запуск бекенду StreamHub (Опціонально)

Якщо ви бажаєте мати власний сервер-парсер стрімінгу (Rezka, Eneyida, UAFlix, UASerials, Kodik):
1. Перейдіть до папки `streamhub`:
   ```bash
   cd streamhub
   ```
2. Запустіть контейнери через Docker Compose:
   ```bash
   docker compose up -d --build
   ```
3. Сервер запуститься:
   - Core API Gateway: `http://localhost:8080`
   - Lampa Adapter: `http://localhost:7011`
4. У Lampa на телевізорі: відкрийте **Налаштування** → **StreamHub** та вкажіть IP вашого сервера (наприклад, `http://192.168.1.50:7011`).

## 🔌 Як додавати сторонні онлайн-джерела (BanderaOnline, Lampa Guide тощо)

Якщо ви знайшли нове джерело (наприклад, на [lampaguide.com/plugins](https://lampaguide.com/plugins) чи в Telegram), є три способи його підключення:

### Спосіб 1: Через меню самої Lampa (на будь-якому пристрої / телевізорі)
1. Відкрийте **Налаштування** (іконка шестірні) → **Розширення** (або Плагіни).
2. Натисніть **«Додати плагін»** (плюсик).
3. Введіть URL-адресу плагіна:
   - Зовнішнє посилання: наприклад, `https://lampame.github.io/main/BanderaOnline/BanderaOnline.js` або `https://bylampa.github.io/cinema.js`
   - Або локальне з вашого хабу: `./plugins/cinema.js` / `./plugins/showy.js` / `./plugins/online_mod.js`
4. Натисніть **«Готово»** та перезапустіть застосунок.
5. *Захист від торентів*: якщо плагін містить у назві або адресі ознаки торент-парсерів (`tracks`, `torr`, `jackett`, `pubtorr`), наш `plugins_black_list.json` автоматично заблокує його встановлення для вашої правової безпеки.

### Спосіб 2: Через автозавантаження (`autoload.json`)
Щоб плагін з'являвся автоматично для всіх користувачів вашого хабу без ручного введення:
1. Відкрийте файл `autoload.json` у корені хабу.
2. Додайте новий блок:
   ```json
   {
     "url": "./plugins/showy.js",
     "name": "Showy (Онлайн)",
     "author": "Showy"
   }
   ```
3. Збережіть і запушіть на GitHub — при відкритті сайту Lampa встановить його автоматично.

### Спосіб 3: Через каталог розширень (`plugins/catalog.json`)
Всі локальні плагіни з цієї збірки вже зареєстровані у [plugins/catalog.json](plugins/catalog.json). Ви можете вмикати та вимикати їх в один клік у каталозі розширень Lampa.

## ⚖️ Юридичне застереження
Цей проєкт є виключно клієнтським інтерфейсом для відображення загальнодоступної інформації про кінематограф із публічних баз даних (TMDB). Він не містить, не хостить і не поширює медіафайли або торенти. Всі потоки транслюються безпосередньо зі сторонніх веб-серверів за ініціативою користувача.
